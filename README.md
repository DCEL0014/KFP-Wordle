# KFP-Wordle

Et Wordle-inspireret browser-spil med arbejdsplads-relaterede ord, lavet i HTML, CSS og JavaScript.

## GitHub Pages

Repo-strukturen er klar til GitHub Pages. `index.html` ligger i roden, så vælg:

- Source: Deploy from a branch
- Branch: main
- Folder: /root
## Sådan spiller du

1. Gæt et arbejdspladsrelateret ord.
2. Brug farverne som hjælp til dit næste gæt.
3. Du har seks forsøg til at finde ordet.
